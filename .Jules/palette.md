## 2025-02-12 - Accessibility on custom DOM components
**Learning:** For custom DOM-based components, like div-based progress bars (`.progress-bar`), explicitly defining `role="progressbar"` along with initial properties like `aria-valuenow="0"` is necessary. Additionally, the `aria-valuenow` attribute must be synchronously updated along with visual width changes via JavaScript in order to communicate progress precisely to screen readers. For keyboard navigability, adding custom explicit `:focus-visible` CSS rules on interactive elements helps users track what is actively selected.
**Action:** When creating or maintaining custom progress bars and input elements in the dashboard, always sync ARIA properties alongside CSS style updates in JavaScript, and maintain robust `:focus-visible` styling for interactive states.
