## 2024-05-24 - Dynamic ARIA Attributes for Custom Progress Bars
**Learning:** In standard HTML elements like `<progress>`, accessibility attributes are automatically maintained by the browser. However, when building custom progress bars (e.g., using a background fill `div` inside a container `div`), screen readers rely on ARIA attributes (`role="progressbar"`, `aria-valuemin`, `aria-valuemax`, and importantly, `aria-valuenow`). Since the UI updates asynchronously via polling, `aria-valuenow` must be explicitly managed by JavaScript alongside the CSS width updates to ensure accurate reporting to screen readers.
**Action:** Whenever creating or modifying custom visually-indicated progress indicators, ensure that dynamic ARIA attributes (like `aria-valuenow`) are updated in the same DOM manipulation block as the visual styles.
