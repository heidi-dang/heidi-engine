## 2026-09-10 - Custom Progress Bar Accessibility and Focus States
**Learning:** Custom UI elements like div-based progress bars lack inherent semantic meaning for screen readers. They require explicit ARIA attributes (`role="progressbar"`, `aria-label`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`) that must be dynamically updated via JavaScript to accurately convey state changes. Also, explicitly defining `:focus-visible` states is necessary to provide clear visual cues for keyboard navigation.
**Action:** When creating custom progress indicators or interactive elements, proactively add and dynamically manage appropriate ARIA attributes. Consistently implement clear `:focus-visible` styles for all focusable elements (like links and selects) to ensure robust keyboard accessibility.
