## 2024-09-14 - Improve accessibility for progress bar and interactive elements
**Learning:** Custom progress bars built with standard HTML/CSS `div`s need specific ARIA roles and attributes (`role="progressbar"`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`) to be properly announced by screen readers. Furthermore, these attributes need to be dynamically updated via JavaScript as the values change, rather than remaining static, to provide real-time feedback to assistive technologies. Additionally, standard focus states might not provide enough visual contrast out-of-the-box in dark-mode themes, necessitating explicit `:focus-visible` styling for interactive elements like links and selects to ensure clear keyboard navigation.
**Action:** When implementing or updating custom visual components like progress bars, always ensure dynamic ARIA attributes are updated synchronously with the visual state in the JavaScript DOM manipulation logic. Always verify that `:focus-visible` styles have sufficient contrast against the current theme for all focusable elements.
